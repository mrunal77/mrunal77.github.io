# Personal Portfolio Website

A responsive personal profile website showcasing projects, skills, and contact information.

## Live Demo

Visit the website at: https://mrunal.vercel.app/

## About

This repository contains the source files for a static portfolio website built with HTML, CSS, and JavaScript. It includes sections for an about summary, portfolio items, and contact details.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Usage

1. Clone the repository.
2. Open `index.html` in your web browser.
